Politique de Confidentialité — Night Rush

Dernière mise à jour : 12 septembre 2026

1. Introduction

Night Rush est un jeu mobile gratuit développé par Celtmen. Cette politique de confidentialité décrit les données personnelles collectées et la manière dont elles sont utilisées.

2. Responsable du traitement

Celtmen
Email : celtmen@yahoo.com

3. Données collectées

3.1 Données fournies par l'utilisateur

Lors de la création d'un compte, vous fournissez :

  • Pseudo : choisi par vous, affiché dans le classement
  • Mot de passe : stocké de manière sécurisée sur nos serveurs (Supabase)

3.2 Données collectées automatiquement

  • Scores et progression : meilleur score, points, skins acquis
  • Plateforme : le système d'exploitation (Android, iOS, Windows, Mac) est envoyé à un webhook Discord pour les statistiques

3.3 Données collectées par des tiers

  • Google AdMob : des publicités récompensées sont affichées dans le jeu. Google peut collecter des données publicitaires (identifiant publicitaire, localisation approximative). Politique de Google

4. Utilisation des données

Les données sont utilisées pour :

  • Sauvegarder votre progression (scores, skins, points)
  • Afficher le classement mondial
  • Permettre la connexion à votre compte sur plusieurs appareils
  • Afficher des publicités pour financer le jeu gratuit
  • Établir des statistiques anonymes d'utilisation (via Discord)

5. Stockage et sécurité

  • Serveur : les données de compte sont stockées via Supabase (hébergé dans l'Union européenne)
  • Local : une copie de votre progression est sauvegardée localement sur votre appareil

6. Partage des données

Nous ne vendons pas vos données personnelles. Les données peuvent être partagées avec :

  • Supabase : hébergement de la base de données
  • Google AdMob : régie publicitaire
  • Discord : webhook pour les statistiques (uniquement la plateforme, aucune donnée personnelle)

7. Conservation des données

Les données de compte sont conservées tant que votre compte est actif. Pour supprimer votre compte et toutes vos données, contactez-nous à celtmen@yahoo.com.

8. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès à vos données
  • Droit de rectification
  • Droit à l'effacement (suppression du compte)
  • Droit à la portabilité
  • Droit d'opposition

Pour exercer ces droits, envoyez un email à celtmen@yahoo.com.

9. Mineurs

Le jeu est accessible à tous. Si vous avez moins de 15 ans (ou l'âge de consentement numérique dans votre pays), demandez l'autorisation à vos parents avant de créer un compte.

10. Modifications

Cette politique peut être mise à jour à tout moment. La date de dernière mise à jour est indiquée en haut de cette page.

11. Contact

Pour toute question : celtmen@yahoo.com
